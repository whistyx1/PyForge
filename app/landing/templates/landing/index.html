CAPABILITIES

Practical deployment machinery, kept in view.

PyForge automates the repetitive work while keeping the plan, commands, and target infrastructure legible.

  • Project analysis

    Detects your Python project and confirms the framework, dependencies, start command, and health check.

  • Docker generation

    Generates a Dockerfile and Docker Compose configuration for the reviewed deployment.

  • SSH server checks

    Checks your Linux server over SSH and confirms Docker is installed before deployment.

  • Reviewable deployment plans

    Shows each command for approval before making changes to your server.

  • Optional PostgreSQL

    Adds PostgreSQL when your project needs it—without making a database mandatory.

  • Logs and health checks

    Displays deployment logs and application health status after startup.

PRACTICAL ANSWERS

Questions before your first deploy.

The operating model is intentionally simple: local tooling, reviewable commands, SSH, and infrastructure you own.

  • Where does PyForge run?

    PyForge runs locally. It analyzes and prepares the deployment on your machine, then connects to your server over SSH.

  • What server do I need?

    A Linux server with Docker installed. PyForge checks the server before deployment.

  • Can I review commands before they run?

    Yes. PyForge shows the deployment plan and commands for approval before it changes your server.

  • Does PyForge generate Docker configuration?

    Yes. It generates a Dockerfile and Docker Compose configuration for the deployment.

  • Is PostgreSQL required?

    No. PostgreSQL is optional and can be included when your project needs it.

  • Which Python frameworks are supported?

    PyForge supports Django, FastAPI, and Flask projects.
